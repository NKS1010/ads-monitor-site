Política de Privacidade — ads-monitor

Última atualização: 24 de novembro de 2026.

O que é

O ads-monitor é uma ferramenta pessoal, de uso interno, usada exclusivamente pelo seu autor para acompanhar e otimizar as próprias contas de Google Ads. Ela não é oferecida ao público.

Quais dados são acessados

Com a autorização do titular, por meio do escopo da Google Ads API (https://www.googleapis.com/auth/adwords), a ferramenta acessa dados das contas de Google Ads autorizadas: campanhas, orçamentos, métricas de desempenho (impressões, cliques, custo, conversões), termos de busca e palavras-chave.

Como os dados são usados

  • Para gerar relatórios, alertas e recomendações exibidos somente ao próprio autor.
  • Para melhorar o desempenho das campanhas, aplicando alterações nas contas (como palavras-chave negativas, pausas e ajustes de orçamento) somente depois de aprovação manual explícita do titular.
  • Os relatórios podem ser analisados com a ajuda de um assistente de IA operado pelo próprio autor. Os dados não são usados para treinar modelos de IA.

Armazenamento e compartilhamento

  • Os dados ficam no computador do autor e em um repositório privado, acessível apenas a ele.
  • Os dados não são vendidos, cedidos nem compartilhados com terceiros.
  • O uso de informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
